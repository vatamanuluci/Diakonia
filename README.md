# Diakonia · Datele bisericii

Dashboard static în limba română, pregătit pentru publicare pe Netlify.

## Publicare

- Public directory: `dist`
- Build command: none
- Entry page: `dist/index.html`

Conectează repository-ul Git la Netlify și selectează setările de mai sus. Proiectul folosește doar indicatori agregați din registrul sursă. Nu adăuga exportul Excel cu date personale în acest repository.

## Sursa metricilor

Indicatorii au fost agregați local din foile disponibile. Datele individuale de identificare, contact și adresă nu sunt incluse în aplicație.
